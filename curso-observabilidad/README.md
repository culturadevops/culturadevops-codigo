## Requisitos

- Docker con Compose.
- Python 3.10+ (para `tienda.py`, `trafico.py` y `receptor.py`; solo biblioteca estándar).

## Cómo ejecutarlo

```bash
cd laboratorio
docker compose up -d
python tienda.py      # la aplicación que se observa
python trafico.py     # en otra terminal: le mete tráfico
```

Grafana queda en http://localhost:3001 (usuario `admin`, contraseña de laboratorio `lab`); se movió del 3000 porque estaba ocupado al grabar. Prometheus en :9090, Loki en :3100, Alertmanager en :9093.
