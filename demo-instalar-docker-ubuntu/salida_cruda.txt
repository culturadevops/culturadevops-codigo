### 1 · Prerrequisitos y la llave GPG oficial
debconf: delaying package configuration, since apt-utils is not installed
$ apt update && apt install ca-certificates curl   (hecho)
$ install -m 0755 -d /etc/apt/keyrings
$ curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
$ chmod a+r /etc/apt/keyrings/docker.asc && ls -l /etc/apt/keyrings/docker.asc
-rw-r--r-- 1 root root 3817 Oct 23 18:00 /etc/apt/keyrings/docker.asc

### 2 · El repositorio apt de Docker

### 6 · El paso post-instalación: el grupo docker
$ groupadd docker
groupadd: group 'docker' already exists
$ getent group docker
docker:x:995:
$ usermod -aG docker ana
$ getent group docker
docker:x:995:ana
ana$ docker ps   (la terminal que ya tenía abierta)
grupos: ana
permission denied while trying to connect to the docker API at unix:///var/run/docker.sock
ana$ newgrp docker   # o cerrar sesión y volver a entrar
ana$ docker run --rm hello-world | head -3
grupos: ana docker

Hello from Docker!
This message shows that your installation appears to be working correctly.
