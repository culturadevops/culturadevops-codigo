# Accesos a servidores y a la nube

Nadie entra a los servidores de producción con usuario y contraseña. El acceso es con llave SSH personal, y las llaves se revisan cada tres meses.

Los permisos de administrador en la nube se piden por una solicitud que dura como máximo ocho horas. Al terminar ese plazo, el permiso se quita solo.

Cuando una persona deja la empresa, sus llaves y sus accesos se quitan el mismo día, antes de las 18:00.
