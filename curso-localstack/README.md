## Requisitos

- Docker con Compose.
- AWS CLI v2.
- Python 3.10+ con `boto3` y `pytest` (lecciones 9-13).
- ⚠️ La imagen `localstack/localstack` pide token de cuenta desde 2026.8; el curso usa la etiqueta `3.8`. Si no te arranca, revisa la documentación de LocalStack.

## Cómo ejecutarlo

1. Copia el compose de la lección 2 a un `docker-compose.yml` y levántalo con `docker compose up -d`.
2. Sigue cada lección con su `EN-PANTALLA.md`. Siempre con `--endpoint-url=http://localhost:4566` y credenciales de mentira (`test`/`test`): la lección 3 explica por qué.
